# OP最適化

- 通常ボタンは選択中のプリセット・レベル・クリティカル条件を使う。アバンダク選択時には専用ボタンへ案内する。プリセット未選択なら確認後に能力なしで実行できる。
- アバンダク用ボタンはアバンダク選択時のみ実行する。現在のレベルと、通常OP・入力済みEXの異なる能力名の数（上限20）による倍率を探索で評価する。
- 両ボタンとも武器通常OP5枠＋防具24枠を対象とする。EX3枠は未入力でも予約し、入力済みEXを変更しない。
- 未入力EXは各枠で異なるEXを装着する想定として種類数に加算する。未入力EXのステータス・条件倍率は仮定せず、実行後の注意表示に未入力数と再最適化の案内を残す。画面の期待値指数には仮想EXを加算しない。
- 通常OPの同系統排他、ユーゼ・ユディの各1個制限を維持する。異能力数は正規化前の能力名で数えるため、別部位の通常版・S版等の使い分けも評価する。
- 貪欲法と1枠交換改善で探索する。全29枠が有効な現在構成からも交換改善を行い、同じ評価条件で良い方を採用する。アバンダクではさらに2枠同時交換を行う。大域最適解の保証はない。手入力の独自能力・未充足枠・無効構成・未所持Sを含む構成は比較用の開始構成にはしない。
- スロット比較側の既知の計算不整合は今回の対象外。

検証: scripts/test_optimizer.cjs を Node.js で実行。ブラウザDOMの代替を使い実データで枠数、排他、EX保持、アバンダク評価、確認・キャンセルを確認する。

## 全属性バルフト系の優先（2026-09-10）
評価の第一優先は威力倍率×通常/クリティカル期待係数×アバンダク倍率（専用時）。武器攻撃力・潜在・リング等、探索中に変わらない倍率は省略する。単純な威力順ではない。

期待値が同点（絶対差1e-12以内）の場合、ユーゼ・ユディの全属性バルフト系の採用数を優先し、次にHP+PPを比較する。貪欲追加・交換改善・現在構成との比較で共通の基準を使う。期待値が高い2属性版は除外しない。

旧探索の検証例（2026-09-10）では、ユーゼ・ユディだけを全枠アルムバルフトへ変えると評価が低下した。しかし、他の能力も同時に変える余地を否定する結果ではなかった。2026-09-11の2枠交換探索では、下記条件で他系列のS/MN等に異能力数を分担させ、全枠アルムバルフトにできることを確認した。下限上限100%やクリ率100%では追加の下限補正の寄与はなくなるため、アルムが常に最強とは限らない。

## 武器属性と部位配置（2026-09-10）
アバンダク探索では、武器種の参照属性が一つも上昇しないユーゼ・ユディ系を候補から除外する。打撃はダシャ・ダホウ、射撃はダシャ・シャホウ、法撃はダホウ・シャホウが有効。全属性版は引き続き候補とし同期待値なら優先する。複合参照は従来の高い側の倍率で評価し、未選択は全属性平均で評価する。

探索後、武器の全属性版と防具の同系統2属性版を交換できる場合、2属性版を武器へ優先配置する。交換前後の評価値と各部位の排他をチェックし、能力集合・異能力数・期待値を維持する。武器は各系統1個までなので、2属性版が複数ある場合は防具にも残り得る。通常最適化にはこの配置処理を適用しない。

## 所持Sと2枠交換探索（2026-09-11）

- アバンダク用ボタンで所持S選択ダイアログを開く。候補一覧はJSONの末尾 ` S` の能力から生成する。初回は全て未選択。「すべて選択」「すべて解除」、Sなし実行、キャンセルに対応。
- 実行が成功した時だけ、能力名の配列を `opt_owned_s_v1` に保存する。構成スロットとは独立した、このブラウザ共通の所持設定。破損保存・新しく追加されたSは未選択に戻す。保存不可の場合は案内する。
- 選択は所持種類の許可リストであり、個数制限・全種類使用の強制ではない。未選択Sは現在構成の開始候補からも除外する。通常最適化・手動選択には制限を適用しない。
- 期待値を最優先とし、同点なら全属性バルフト数、次にHP+PPを優先する。S採用数自体は目的関数にしない。
- 1枠交換で改善が止まった構成に対し、2枠同時交換を最大20ラウンド探索する。単独でも部位排他を満たす変更同士の組み合わせに限定し、組合せ後の排他と異能力数を再確認。乗数の差分評価で高速化し、採用前に全能力から再計算する。各採用後に1枠交換改善も再実行する。
- 複合参照の最大値・未選択時の平均、下限上限、EXの重複名、異能力数20種上限は共通の評価関数を使用する。3枠以上の同時変更等も含めた大域最適解は保証しない。

再現条件：付属テストの打撃参照、クリ率15%、クリ倍率1.2、武器下限50%、防具基礎倍率なし、EX未入力3種類を仮定、アバンダクLv5、2026-09-11のJSON。全S使用可で、旧評価値6.125377264092466 → 新評価値6.139789916478566（約+0.2353%）。S系は2種類→4種類、ユーゼ・ユディ2属性版は4枠→0枠。ロイスハルフィニリアSは選択可能だが、この結果ではより高威力のエミス系と排他なので採用しない。全S採用が必ず最適とは限らない。

同じ検証条件ではSなしでも他の通常/MN版の使い分けで同期待値に到達する（HP/PPなどは異なる）。「Sが増えれば必ず期待値が上がる」という意味ではない。また、これはゲーム実測でもユーザー保存構成の再現でもない。

検証：既存回帰テストに、所持Sなし/一部/全部、未所持Sを含む現在構成、2枠交換改善、ダイアログの保存/復元/キャンセル/破損保存/保存失敗を追加。ローカルブラウザでも選択→実行→再表示とキャンセルを確認。
