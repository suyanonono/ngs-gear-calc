# 武器プルダウンの表示順

武器の表示順は index.html の WEAPON_DISPLAY_GROUPS で定義する。data/weapons.json の記述順とは独立している。

- シリーズ単位でまとめ、最新段階の実装日が新しいシリーズを上に置く。同日実装は既存の順を維持する。
- グループ内は最新段階→アップグレード元の順。旧段階には「└」「アップグレード元」を表示する。
- 新シリーズ追加時はグループを先頭に追加する。アップグレード追加時は既存グループの先頭に新武器を追加し、グループ全体を先頭に移す。
- 定義内の武器名は weapons.json の n と完全一致させる。未登録の武器は欠落させず末尾に表示する。
- weapons.json の既存項目は並べ替えず、新武器は末尾に追記する。配列番号を選択肢の value として維持するため、従来の保存・復元・計算との互換性を保つ。
